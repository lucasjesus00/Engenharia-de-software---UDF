# 2° Semestre - Engenharia de Software

Esta pasta agrupa as disciplinas do 2° semestre. Dentro dela você encontrará uma subpasta para cada disciplina com:

- Apresentação da disciplina
- Material de aula (slides, anotações)
- Exercícios e listas de prática
- Projetos e trabalhos práticos
- Recursos e bibliografia

Subpastas:
- Desenvolvimento Front-End Para Web: foco em HTML/CSS/JS e projetos de interfaces.
- Algoritmos e Pensamento Computacional: exercícios, algoritmos e desafios.
- Design Profissional: wireframes, protótipos e entregáveis de design.
- Modelagem de Banco de Dados: diagramas, scripts SQL e testes de consultas.

Use as pastas das disciplinas para organizar o conteúdo por aula, semana ou tipo de atividade.
